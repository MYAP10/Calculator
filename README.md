# Calculator

A basic calculator built using HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division.
- Clear and delete buttons.
- Decimal number support.
- Displays the calculation and result.
- Handles division by zero.

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

Practiced JavaScript functions, event listeners, variables, and basic DOM manipulation while building this project.
